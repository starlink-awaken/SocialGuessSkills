# 扩展 Agent 方法论

> 本文档定义五个新增 Agent 的分析方法与输出规范，用于扩展现有社会系统建模框架。

---

## Environmental Agent（环境）

### 领域概述
聚焦自然与人造环境的长期约束：生态承载、气候波动、污染风险与资源再生能力，评估环境边界对社会系统的塑形作用。

### 分析框架（3-4维度）
- **承载与再生**：资源可再生速率 vs 消耗速率
- **脆弱性与极端事件**：自然灾害、气候异常、季节性波动
- **环境外部性**：污染、生态退化与代际成本
- **空间耦合**：地理分布、生态廊道与空间隔离

### 关键概念
生态承载力、气候韧性、环境外部性、资源循环、空间异质性、临界阈值

### 输出示例
```json
{
  "conclusion": "当前系统在水资源再生率低于消耗率的情境下，必须建立周期性配额与节水激励，否则将在两年内触发供水断裂。",
  "evidence": ["流域年补给量与人口需求对比显示缺口约18%"],
  "risks": ["干旱年份引发的资源冲突", "水体富营养化导致可用水下降"],
  "suggestions": ["建立分级用水定价", "引入雨水回收基础设施"],
  "falsifiable": "若连续三季降水量高于历史均值20%，则配额压力显著降低"
}
```

## Demographic Agent（人口）

### 领域概述
关注人口结构与动态：年龄、迁移、规模与密度变化如何影响需求、劳动力与社会张力。

### 分析框架（3-4维度）
- **结构与依赖比**：年龄结构、劳动力与被抚养人口比例
- **流动与迁移**：人口流入流出、技能迁移与社会融合
- **规模与密度**：人口规模、空间密度对资源与治理的压力
- **增长与衰退**：出生率、死亡率与长期趋势

### 关键概念
人口转型、依赖比、迁移冲击、人口密度阈值、结构性失衡

### 输出示例
```json
{
  "conclusion": "老龄化加速将导致劳动力缺口与公共支出上升，需提前调整福利与劳动参与结构。",
  "evidence": ["65岁以上人口比例三年内由14%升至19%"],
  "risks": ["劳动供给不足", "代际资源分配矛盾"],
  "suggestions": ["推行弹性退休", "引入技能导向型迁移政策"],
  "falsifiable": "若劳动参与率提升5个百分点，劳动力缺口将显著缓解"
}
```

## Infrastructure Agent（基础设施）

### 领域概述
评估交通、能源、水利、通信等基础设施的可靠性与扩展性，判断其对社会系统稳定性的底座作用。

### 分析框架（3-4维度）
- **可靠性与冗余**：关键设施故障率与备份能力
- **容量与扩展**：服务上限、可扩容性与瓶颈节点
- **互联与级联风险**：系统耦合度、故障传播路径
- **维护与更新**：生命周期、维护投入与技术替换

### 关键概念
关键基础设施、冗余设计、级联故障、瓶颈效应、生命周期维护

### 输出示例
```json
{
  "conclusion": "电力系统单点故障风险高，一旦主干变电站失效将造成全域停摆。",
  "evidence": ["主干变电站承担72%的负载且无同级备份"],
  "risks": ["级联停电", "通信系统连锁崩溃"],
  "suggestions": ["部署分布式微电网", "提升关键节点冗余度"],
  "falsifiable": "若新增两处同级变电站，停电概率下降超过40%"
}
```

## Technology Agent（技术）

### 领域概述
聚焦技术渗透率、创新节奏与技术风险，评估技术对效率、治理与风险结构的改变。

### 分析框架（3-4维度）
- **渗透与采纳**：关键技术覆盖率与使用门槛
- **创新与替代**：新技术替代旧系统的速度与阻力
- **技术外部性**：自动化失业、数据风险、伦理问题
- **安全与韧性**：网络安全、系统稳定性与失效模式

### 关键概念
技术扩散曲线、替代成本、技术债、数字鸿沟、系统韧性

### 输出示例
```json
{
  "conclusion": "数字治理平台可显著提升分配效率，但在低数字素养群体中会造成新的排斥效应。",
  "evidence": ["线上申领使用率仅为高教育群体的32%"],
  "risks": ["数字排斥", "系统性数据偏差"],
  "suggestions": ["保留线下渠道", "提供数字素养培训"],
  "falsifiable": "若培训覆盖率达到60%，线上使用率将提高到50%以上"
}
```

## Historical Agent（历史）

### 领域概述
通过历史案例与长期路径依赖分析，识别制度、文化与结构性惯性对当前系统的制约与启示。

### 分析框架（3-4维度）
- **路径依赖**：历史制度与惯性对现状的锁定效应
- **周期与重复模式**：历史循环、相似情境的结果
- **断裂与转折**：关键历史事件的结构性影响
- **记忆与叙事**：集体记忆与合法性基础

### 关键概念
路径依赖、历史循环、临界转折、集体记忆、制度遗产

### 输出示例
```json
{
  "conclusion": "历史上多次资源危机均因分配不公引发冲突，当前政策若忽视公平性，将重现社会撕裂。",
  "evidence": ["三次危机均出现粮食垄断与暴力冲突记录"],
  "risks": ["制度合法性削弱", "冲突重复"],
  "suggestions": ["建立透明分配机制", "引入历史案例审议流程"],
  "falsifiable": "若分配透明度评分提升至80%，冲突事件下降30%"
}
```
